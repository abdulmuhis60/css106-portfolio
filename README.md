# Student Portfolio and Academic Management Website

COS 106 – Introduction to Web Technologies, Term Project

## Pages
- `index.html` – Homepage (name, photo, welcome message, biography, intro video)
- `about.html` – Educational background (table), career aspirations, skills, hobbies
- `projects.html` – Three sample projects with images and links
- `planner.html` – Interactive academic planner (add, complete, delete tasks)
- `contact.html` – Contact form with JavaScript validation

## Technologies
- HTML5 (semantic elements, forms, tables, images, links, lists, video)
- CSS3 (external stylesheet, Flexbox, Grid, media queries, transitions, animations)
- JavaScript (event handling, DOM manipulation, form validation, arrays, functions)
